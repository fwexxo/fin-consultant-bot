# Финансовый консультант

Телеграм-бот для личной бухгалтерии в трёх валютах. Пишешь ему как человеку —
«кофе 5 руб», «на карту пришло 20000», «сколько я трачу на еду?» — он разбирается
сам: записывает, отвечает или переспрашивает.

```
Ты:  на карту пришло 20000₽
Бот: Готово, на Карте RUB теперь 20000.00 RUB.

Ты:  сколько всего у меня на счетах?
Бот: Всего 3712.46 BYN:
     — Карта BYN: 3000.00 BYN
     — Карта RUB: 19995.00 RUB (≈712.46 BYN по курсу НБРБ)

Ты:  отмени последнюю запись
Бот: Отменил кофе на 5 RUB. Остаток на Карте RUB: 20000.00 RUB.
```

Бот рассчитан на **одного пользователя** и отвечает только владельцу.

## Что умеет

- **Свободный текст.** Не команды и не формы — обычные фразы.
- **Три валюты** (RUB / BYN / USD). Счета живут каждый в своей валюте,
  курс фиксируется на дату операции. Курсы берутся с API Нацбанка РБ.
- **Фото.** Скинь чек или экран заказа — суммы достанет с картинки.
- **Голосовые.** Расшифровка на своём сервере, без сторонних сервисов.
- **Регулярные платежи** с напоминанием за N дней. Срок задаётся числом
  месяца или «последним числом» — для февраля это разные вещи.
- **Автоприём СМС от банка** (macOS). Уведомления о тратах записываются
  сами, ты только читаешь сводку.
- **Отчёты и прогноз.** Расходы по категориям, норма сбережений, остаток
  с учётом ещё не оплаченных обязательств.

## Чего не умеет намеренно

Бот **не даёт инвестиционных советов** и не рекомендует, куда вложить деньги.
Он считает и объясняет твои собственные деньги — решения остаются за тобой.

## Как устроен

Три слоя с жёсткой границей между ними:

| Слой | Чем сделан | Почему так |
|---|---|---|
| Учёт | TypeScript + SQLite | Цифры должны быть воспроизводимыми. Тестируется без сети и без Claude. |
| Общение | Claude Agent SDK с инструментами к базе | Свободный текст, фото, голос — там, где модель сильнее правил. |
| Приём СМС | Регулярные выражения | Формат банковских СМС жёсткий: регулярки надёжнее, быстрее и бесплатны. |

Claude работает **по подписке Max**, а не по API-ключу — токены не тратятся.

Подробный дизайн и обоснование решений:
[`docs/superpowers/specs/`](docs/superpowers/specs/)

## Установка

Пошаговая инструкция — **[docs/INSTALL.md](docs/INSTALL.md)**.

Коротко, чтобы попробовать локально:

```bash
npm install
cp .env.example .env      # заполнить TELEGRAM_BOT_TOKEN
npm run migrate
npm run seed              # счета и примеры регулярных платежей
npm start                 # бот скажет твой OWNER_ID — впиши в .env и перезапусти
```

Что понадобится:

| | Зачем | Обязательно |
|---|---|---|
| Node.js 22+ | среда выполнения | да |
| Токен от [@BotFather](https://t.me/BotFather) | сам бот | да |
| Подписка Claude Max | разбор текста, фото, ответы | да |
| Сервер (VPS) | круглосуточная работа | нет, можно локально |
| `whisper.cpp` | голосовые | нет |
| Мак с пересылкой СМС | автоприём трат | нет |

## Разработка

```bash
npm test          # 161 тест, без сети и без Claude
npm run dev       # запуск с автоперезагрузкой
npx tsc --noEmit  # проверка типов
```

Слой учёта покрыт полностью: арифметика балансов, конвертация по курсу,
границы месяцев (28/29/30/31), високосный год, идемпотентность приёма СМС.
Парсер банковских СМС проверялся на 1015 реальных сообщениях.

## Структура

```
src/
  config.ts     настройки из окружения
  core/         учёт: деньги, даты, счета, операции, курсы, отчёты
  db/           схема и миграции
  claude/       агент и инструменты к базе
  bot/          телеграм: доступ, команды, фото, голос
  speech/       расшифровка голосовых
  ingest/       чтение и разбор банковских СМС
  jobs/         напоминания по расписанию
  cli/          приём СМС на сервере
  mac/          наблюдатель за СМС на маке
deploy/         systemd-юнит, выкат, бэкапы
docs/           инструкция, дизайн, план реализации
```
